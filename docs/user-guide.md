# User Guide

## Core Shortcuts

- `Ctrl+N`: new document
- `Ctrl+O`: open file
- `Ctrl+S`: save file
- `Ctrl+F`: search
- `Ctrl+B`: bold
- `Ctrl+I`: italic
- `Ctrl+K`: insert link
- `Ctrl+P`: print

## Editing

- The editor supports split view, editor-only view and preview-only view.
- Press `Enter` inside a list item to continue the list automatically.
- Drag and drop Markdown files to open them.
- Drag and drop image files to insert image markup.
- The Preferences window is movable and stays outside the main editor surface.

## Search

- Opening search with selected text pre-fills the search field automatically.
- Search and replace are available from the search bar.

## Preview

- The preview is rendered as embedded HTML with WebKitGTK, not as a simplified text approximation.
- The preview supports headings, lists, task lists, blockquotes, code blocks, images, tables and horizontal rules.
- The outline panel can be shown on demand and lets you jump to headings.

## Export and Print

- `Export as HTML` writes the same themed HTML representation used by the preview.
- `Export as PDF` and `Print` are generated from the rendered preview, so they preserve the Markdown formatting.
- PDF export uses a compact print stylesheet to fit more content per page than the on-screen preview.

## Recovery

- The application can auto-save recovery data.
- Restoring the previous session on startup can be enabled or disabled in Preferences.

## Styles

- Available preview styles: `Default`, `Slate`, `Ivory`, `Nocturne`, `Ember`, `Splendor`, `Modest`, `Retro`, `Air`.
- Each style changes more than color: typography, spacing, blockquotes, code blocks and document framing also vary.
